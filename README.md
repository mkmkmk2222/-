# 나만의 돌림판

설치 없이 브라우저에서 실행되는 한국어 돌림판입니다.

- 선택지 2~30개를 자유롭게 입력할 수 있습니다.
- `정환` 또는 `림컴`이 포함된 항목은 원판에 표시되지만 선택되지 않습니다. 공백과 보이지 않는 구분 문자도 제거한 뒤 비교합니다.
- 추가 제외 단어를 지정할 수 있습니다.
- 기본 회전 속도는 1.5배이며, 0.75~2.5배 사이에서 조절할 수 있습니다.
- 회전 시간은 4~12초 사이에서 조절할 수 있습니다.
- 서서히 가속하고 감속하며, 멈춘 칸과 표시되는 결과가 일치합니다.
- 효과음과 스페이스바 실행을 지원합니다.

`index.html`을 열면 인터넷 연결 없이도 사용할 수 있습니다. GitHub Pages에서는 이 폴더의 파일을 저장소 루트에 게시하면 됩니다.

이름과 설정은 각 방문자의 열린 페이지에서만 유지되며 서버로 전송되지 않습니다. 새로고침하면 기본 설정으로 돌아갑니다.
